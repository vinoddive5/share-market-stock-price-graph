# Share Market Stock Price Graph

## Project Description
A simple Share Market Graph project developed using ASP.NET MVC and C#. It displays stock prices of different companies using graphical charts.

## Technologies Used
- C#
- ASP.NET MVC
- .NET Framework
- System.Web.Helpers

## Features
- Displays stock prices of different companies.
- Generates graphical representations.
- Supports Line, Column, Pie, and Doughnut charts.

## Companies Included
- State Bank of India
- Bajaj Finance
- TCS
- Infosys
- Axis Bank
- Tata Steel

## Output
Displays stock market prices in graphical format.
